ICS Cyber Heroes — GitHub Pages upload

1. Create a PUBLIC GitHub repository (e.g. ics-cyber-heroes).
2. Upload ALL 11 HTML files from this ZIP to the repository ROOT (not into a subfolder).
3. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Wait for GitHub Pages to publish. The homepage is at https://YOUR-USERNAME.github.io/ics-cyber-heroes/
5. Test all ten game buttons and certificate downloads.

Note: the URL above is an example, not a live URL. Avoid publishing student names or scores.
